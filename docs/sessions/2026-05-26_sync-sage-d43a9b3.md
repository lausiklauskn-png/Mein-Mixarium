## Behobene Befunde (aus Sage-PRs #173 + #174)

1. **Doppel-Tooltips weg** (#173) — `title`-Attribut auf Slot-Buttons
   entfernt, `aria-label` voll. (Bereits seit PR #56 im Endknoten.)
2. **Self-Heartbeat-Fallback in Modul 17** (#174) — Widget feuert
   `sbkim:alive` selbst periodisch, falls Modul 02 stumm bleibt.
3. **`dispatchAliveOnce` auch in `loadIdentity`** (#173) — Cache-
   geladene Identität feuert `sbkim:alive`. (Bereits seit PR #56.)
4. **Modul 02 `_meta.ready`-Getter** (#173) — neuer Probe-Pfad für
   das Widget. (Bereits seit PR #56.)
5. **Atmungs-Ring als `box-shadow`-spread auf der Lampe selbst** (#174)
   — von `::after` mit hardcoded `left:calc(...)` umgebaut auf
   `box-shadow:0 0 0 0` auf `::before` (Lampe-relativ). Ring ist immer
   zentriert um die Lampe, unabhängig vom Slot-Padding.
6. **`#sbkim-widget`-Prefix für CSS-Spezifität** (#174) — schlägt
   PWA-`button { padding: ... }`-User-Agent-Overrides, die sonst Lampe
   + Label verschoben und einen grauen Button-Rand zeigten.
