📲 Installations-Test

Der Knopf wird aktiv, sobald Chrome meldet, dass die App installierbar ist.

So testest du
  1. Diese Seite in Chrome öffnen (nicht aus einer anderen App heraus).
  2. Zuerst über das Chrome-Menü (⋮ → „App installieren“ / „Zum Startbildschirm hinzufügen“) installieren und das neue Symbol antippen.
  3. Kommt „konnte nicht geöffnet werden“: zurück in Chrome auf diese Seite und „Bericht an GitHub senden“ tippen.
  4. Danach die Test-App wieder entfernen und mit dem großen Knopf oben installieren — und noch einmal senden.
