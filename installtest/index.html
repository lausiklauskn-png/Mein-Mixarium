📲 Installations-Test

So testest du — nur über das Chrome-Menü
  1. Im echten Chrome öffnen. Siehst du oben eine schwarze Leiste mit ✕ und ⌄, bist du in einem App-internen Fenster. Dann ⋮ → „In Chrome öffnen“.
  2. „Protokoll löschen“ tippen.
  3. Chrome-Menü ⋮ → „App installieren“ bzw. „Zum Startbildschirm hinzufügen“ → bestätigen.
  4. Das neue Symbol auf dem Startbildschirm antippen.
  5. Was auch passiert: zurück in Chrome auf diese Seite, „Bericht kopieren“ und mir schicken.

Diese Seite hat keinen Installieren-Knopf. Sie schaut nur zu: wann Chrome „installierbar“ meldet, wann das Menü den Fokus nimmt, was installiert wird und ob die App danach wirklich startet.

Befund dieser Sitzung

    Protokoll (bleibt auf dem Gerät gespeichert, auch zwischen Browser und installierter App)
